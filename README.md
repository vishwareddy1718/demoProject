# Iris Species Predictor

A Flask web app that predicts an iris species from sepal and petal measurements using a trained scikit-learn model.

## Run locally

1. Install Python 3.
2. Install dependencies: `pip install Flask joblib numpy scikit-learn`.
3. Run `python app.py`.
4. Open http://127.0.0.1:5000/.

The trained model, label encoder, and scaler are included as Joblib files.
